D. KESIMPULAN
---------------------------------------------------------------------

Pengujian Pertemuan 11 pada aplikasi SIKURSUS Desktop dilakukan terhadap
12 skenario (T01-T12). Hasilnya: seluruh skenario berhasil dan sesuai
dengan hasil yang diharapkan.

1. Autentikasi berjalan dengan benar. Login dengan kolom kosong atau
   password salah ditolak, sedangkan akun admin dan operator berhasil
   masuk. Password di tabel users tersimpan dalam bentuk hash PBKDF2,
   bukan teks biasa.

2. Session dan role berfungsi. Dashboard menampilkan username dan role
   dari UserSession. Akun ADMIN dapat mengakses seluruh menu Master,
   sedangkan akun OPERATOR hanya dapat mengakses menu Peserta
   (Instruktur, Kursus, dan Kelas nonaktif).

3. Navigasi antar modul berjalan baik. WindowManager mencegah
   PesertaFrame terbuka berkali-kali, dan menutup form child dengan
   tombol X tidak menutup Dashboard karena memakai DISPOSE_ON_CLOSE.

4. Logout bekerja sesuai alur: semua form child ditutup, session
   dihapus, lalu aplikasi kembali ke LoginFrame. Menu Tutup Aplikasi
   menampilkan konfirmasi sebelum program berhenti.

5. Saat MySQL dimatikan, aplikasi menampilkan pesan database error dan
   tidak berhenti tanpa penjelasan.

6. Popup menu pada Dashboard dapat ditampilkan melalui klik kanan.

7. Icon menu dimuat dari resource project (getResource), bukan dari
   path komputer pribadi, sehingga tetap tampil setelah project
   dipindahkan ke folder lain.

Dengan demikian, alur Login -> Session -> Dashboard -> Role -> Navigasi
telah berjalan sesuai tujuan praktikum Pertemuan 11. Hal yang masih
perlu dilengkapi pada tahap berikutnya adalah modul CRUD Instruktur,
Kursus, dan Kelas yang saat ini masih berupa kerangka form, serta modul
Transaksi dan Laporan yang akan dikembangkan pada pertemuan berikutnya
(Laporan dengan JasperReports pada Pertemuan 12).
