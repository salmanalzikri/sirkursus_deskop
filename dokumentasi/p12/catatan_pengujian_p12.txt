B. KENDALA YANG DITEMUI DAN PENYELESAIANNYA
---------------------------------------------------------------------

1. Versi Jaspersoft Studio yang diberikan dosen adalah 6.20.0, sedangkan
   panduan menyebut 6.21.5.
   Penyelesaian: dependency di pom.xml disamakan menjadi jasperreports
   6.20.0 agar file .jasper kompatibel dengan runtime.

2. Package report sempat salah nama. Rename yang pertama justru mengubah
   nama class menjadi "report", sedangkan package-nya masih
   "ReportService", sehingga muncul error merah pada baris package.
   Penyelesaian: class dikembalikan menjadi ReportService, lalu package
   di-rename menjadi "report" (huruf kecil).

3. PesertaFrame tidak memiliki tab Design, sehingga tombol tidak dapat
   ditambah lewat drag and drop.
   Penyelesaian: memakai tombol yang sudah ada di kode PesertaFrame dan
   mengisi event-nya dengan
   report.ReportService.tampilkanLaporanPeserta();

4. Muncul pesan "No suitable driver found for
   jdbc:mysql://localhost:3306/db_sikursus" setelah dependency
   JasperReports ditambahkan.
   Penyelesaian: dependency MySQL Connector/J di pom.xml diperiksa dan
   dipastikan ada, lalu dilakukan Clean and Build.

5. NetBeans menampilkan pesan "not enough space in your temp folder"
   saat mengunduh indeks Maven.
   Penyelesaian: ruang drive dibersihkan. Masalah ini tidak memengaruhi
   kode aplikasi.

---------------------------------------------------------------------
C. KESIMPULAN
---------------------------------------------------------------------

Praktikum Pertemuan 12 berhasil dikerjakan. Laporan peserta dirancang di
Jaspersoft Studio dengan sumber data JDBC ke database db_sikursus,
ditampilkan pada Preview, lalu diekspor menjadi PDF. File
laporan_peserta.jasper hasil kompilasi diletakkan pada resource project
(src/main/resources/report/) dan dipanggil dari tombol Cetak pada
PesertaFrame melalui class ReportService, sehingga JasperViewer
menampilkan data peserta yang sama dengan database.

Hal penting yang dipelajari: versi Jaspersoft Studio dan library
JasperReports harus sama (6.20.0) agar file .jasper dapat dibaca, driver
MySQL pada Jaspersoft Studio dan pada project Java adalah dua classpath
yang terpisah, dan viewer dibuka dengan viewReport(print, false) agar
menutup viewer tidak menutup seluruh aplikasi.

Tahap berikutnya: membuat laporan pendaftaran dengan query JOIN
(peserta, kelas, kursus, dan status pendaftaran).
